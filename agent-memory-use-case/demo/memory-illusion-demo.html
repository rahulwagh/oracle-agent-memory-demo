Hidden fact #1

Why does less beat more?

A focused context concentrates attention on what matters.
A full transcript spreads attention across 79 turns of noise.

The goal was never "fit more into the window."
The goal is deciding what deserves to be there.
Bigger context windows don't solve memory. Curation beats accumulation — and curation is a data-management problem.

Five invisible facts behind every AI chat

∞ replay
The model is stateless. Your whole conversation is re-uploaded on every message — the "memory" you feel is a re-run.
13,900 vs 1,300
Tokens per request at turn 80: flat history vs. a memory layer. That's a 10.7× tax for pretending replay is memory.
48 : 13
Bounded, curated context beat the complete transcript — even though the transcript held every fact.
"Memory updated"
= an LLM extracted facts about you and wrote them to a database, scoped to you, your agent, your thread.
93.8%
LongMemEval accuracy when memory is treated as a managed database lifecycle: extract → consolidate → retrieve → revise.
DB problem
Persistence, semantic indexes, scoping, governance, revision — agent memory's wish-list is a database spec.
